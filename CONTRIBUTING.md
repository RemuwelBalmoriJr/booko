# Contributing

1. Claim an issue by commenting on it.
2. Create a branch: `git checkout -b your-name/issue-title`.
3. Make your change and commit with a clear message.
4. Push your branch: `git push -u origin your-name/issue-title`.
5. Open a pull request against `main`.
6. Ask a teammate to review it.
7. Address feedback with follow-up commits.
8. Merge once approved.
